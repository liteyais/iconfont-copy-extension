# iconfont-copy-extension
iconfont-copy一键复制svg代码


## 还在为从 iconfont 下载图标、复制 SVG 代码而反复点击弹窗、调整尺寸吗？ 这款扩展彻底简化你的工作流，让你专注于设计本身。
1、一键复制 SVG / PNG：鼠标悬停图标或插画，点击复制按钮，即可将 SVG 代码或 PNG 图片写入剪贴板，无需打开任何弹窗。

2、独立尺寸设置： 图标与插画可分别设置导出尺寸（4~5000px），满足不同场景需求。图标默认 24px，插画默认 500px。

3、单色图标颜色设置 ： 针对单色图标，可自由指定替换颜色（如 #ff0000）。复制或下载时自动应用该颜色，无需手动修改 SVG 源码，特别适合需要统一品牌色或反复调整颜色的场景。留空则保持图标原色，多色图标不受影响。

4、格式自由切换： 支持复制为 SVG 源码或 PNG 位图，方便直接粘贴到文档、设计软件或聊天窗口。

5、列表优化布局： 一键开启紧凑模式，让搜索结果展示更多内容，浏览效率倍增。

6、智能直接下载（仅图标）： 开启后，点击原生下载按钮将直接保存 SVG 文件到本地，并自动以图标命名（如“安全保障.svg”），告别弹窗干扰。

## 适用场景
设计师、前端开发者、内容创作者 —— 任何需要频繁从 iconfont 获取素材的人，都能节省 80% 的重复操作时间。
